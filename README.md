## Stack

- Next.js 15 + React 19 + TypeScript strict + Tailwind 4
- Supabase self-hosted (auth.purama.dev) + Postgres RLS
- Stripe (abonnements) + Treezor (redistribution mensuelle SEPA)
- Anthropic Claude (Aria — Sonnet 4.6 main, Haiku 4.5 fast, Opus 4.7 premium)
- next-intl (16 locales)
- MapLibre + MapTiler (impact mondial)
- Vercel + EAS (mobile post-SASU)
